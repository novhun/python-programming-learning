## 🚀 How to Run the Code

Every part folder contains a standalone, runnable script (`main.py`) that demonstrates all concepts with clear formatted console outputs.

To run any part, open your terminal and navigate to the project directory:

```bash
# Example: Run Part 1 (Basics)
python3 part-01-basics-and-syntax/main.py

# Example: Run Part 5 (OOP)
python3 part-05-oop-fundamentals/main.py

# Example: Run Part 11 (FastAPI In-Process Demo or Live Server)
python3 part-11-fastapi-modern-apis/main.py

# Example: Run Part 12 (Django In-Process Demo or Live Server)
python3 part-12-django-web-framework/main.py

# Example: Run Part 13 (SQLAlchemy 2.0 ORM)
python3 part-13-sqlalchemy-orm/main.py

# Example: Run Part 14 (Alembic Migrations)
python3 part-14-alembic-migrations/main.py

# Example: Run Part 15 (CRUD & Repository Pattern)
python3 part-15-database-crud-patterns/main.py
```

## 💡 Learning Strategy
1. **Read the `README.md`** inside each part folder to understand the concepts, syntax rules, and architectural trade-offs.
2. **Execute the `main.py`** script and observe the console output.
3. **Inspect the code** in `main.py` to see how the theoretical concepts are implemented in clean, idiomatic Python.
4. **Complete the exercises** listed at the bottom of each module's `README.md`.
